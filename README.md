# FretLab 🎸

**FretLab** — это гитарная веб-платформа, объединяющая ИИ-генерацию соло, гитарный процессор с реальными эффектами, тренировки слуха, анализ игры, занятия под бэк-треки со стримингов и глубокое изучение музыкальной теории прямо на грифе.

Проект разработан как отзывчивое одностраничное приложение (SPA) на базе **React** и **TypeScript** с упором на производительность звукового движка в реальном времени.

> 🔗 **Продакшн:** [https://latters8.github.io/FretLab/](https://latters8.github.io/FretLab/)

## 🧭 Модули платформы

FretLab построен вокруг **6 основных модулей**, переключение между которыми доступно через боковую панель навигации (или хоткеи `Ctrl+1…6`):

| Модуль | Иконка | Описание |
|--------|--------|----------|
| **Fretboard Engine** | 🎸 | Интерактивный гриф гитары с подсветкой нот и ступеней |
| **Chord Dictionary** | 📖 | Словарь аккордов с аппликатурами и озвучкой |
| **Solo Generator** | 🎼 | AI-генерация соло в DAW-сетке |
| **FretLab Rig** | 🎛️ | Гитарный процессор с педалями эффектов |
| **Practice Dashboard** | 🏋️ | Тренировки и отслеживание прогресса |
| **Game Room** | 🎮 | Браузерные игры для отдыха |

## 🚀 Ключевые возможности

### 1. 🎸 Fretboard Engine — Интерактивный гриф
* **Визуализация теории:** Динамическое отображение нот, интервалов и CAGED-аппликатур на виртуальном грифе в соответствии с выбранной тональностью.
* **Огромная база ладов:** Полная поддержка диатоники, пентатоники, блюзовой гаммы, гармонического/мелодического минора, церковных ладов (Dorian, Phrygian, Lydian, Mixolydian, Aeolian, Locrian), симметричных ладов (Altered) и арпеджио (`maj7_arp`, `min7_arp`, `dom7_arp`, `dom9_arp`).
* **Строи и накладки:** Стандартный / Drop D / Drop C / D Standard, выбор материала накладки (Ebony, Rosewood, Maple, Glass) и цвета ладов.
* **Звук нот:** Клик по любой ноте грифа воспроизводит её через аудиодвижок.

### 2. 📖 Chord Dictionary & Diatonic Harmony
* **Словарь аккордов:** Полный справочник гитарных аккордов с визуализацией аппликатур на грифе и озвучкой.
* **Диатоническая гармония:** Панель `DiatonicChords` показывает аккорды текущей тональности с фильтрами **DIA / 7TH / 9TH / ALT** (трезвучия, септимы, нонаккорды, альтерации).
* **Квинтовый круг** (`CircleOfFifths`): Интерактивный SVG-круг для быстрой смены тональности (мажор/минор) — кликом по любой ступени вы меняете Key и Mode грифа.

### 3. 🎼 AI Studio & Solo Generator
* **Синхронизированная генерация:** Умный генератор аккордовых прогрессий и мелодических соло-линий, жёстко завязанный на тактовую сетку.
* **Расширенное соло (32–64 такта):** Генерация длинных фраз с 9 стилями (**Blues, Rock, Jazz, Fusion, Metal, Funk, Country, Pop, Classical**), настройкой сложности (1–5), вариативности, структурой **call-response** и развитием мотива (**motif development**).
* **DAW-сетка:** Визуализация треков (Chords, Solo, Bass, Drums) на кастомной адаптивной SVG-сетке со штилями нот, длительностями и подсветкой активного лада в реальном времени.
* **BBS-Тайминг (Bars:Beats:Sixteenths):** Вся логика воспроизведения переведена на музыкальные доли, что полностью исключает рассинхрон и микрозадержки при смене BPM.
* **Драм-машина:** Набор готовых паттернов ударных + генерация случайных паттернов (**Random**), мутация (**Mutate**), генерация 5 паттернов сразу (**5x**) и восстановление из истории.
* **Автоматический бас:** Движок автоматически генерирует плотную басовую линию (корневые ноты + квинты) под текущую прогрессию.
* **Интерактивный режим:** Подсказки рекомендуемых нот, фраз и предсказание следующей ноты (`PhraseSuggestionOverlay`).
* **Редактор импровизации:** Клик по аккорду в сетке открывает меню с диатоническими и рекомендованными аккордами для замены.
* **Советы от легенд:** `AnimatedTipBlock` генерирует советы к сгенерированному соло.
* **AI Phrase Builder (табулатура):** Отдельный генератор «человеческих» фраз с ритмическими/мелодическими паттернами, артикуляцией (hammer, pull, slide, bend, vibrato) и регулировкой скорости воспроизведения.

### 4. 🎛️ FretLab Rig — Гитарный процессор
* **Реальный процессор эффектов** на базе `AudioWorklet` (128 samples) с обработкой живого звука с микрофона в реальном времени.
* **Педали эффектов:** Tuner, Noise Gate, Tube Drive, High Gain, Amp EQ, **Cabinet IR**, Modulation (Chorus / Flanger / Phaser / Tremolo / Vibrato), Delay, Reverb и Master.
* **SVG-ручки:** Вращающиеся ручки (драг вертикально) с параметрами каждой педали + кнопки bypass On/Off.
* **Cabinet IR:** Загрузка собственных импульсных откликов (.wav / .aif / .aiff) + автозагрузка IR по умолчанию.
* **Визуализация:** UV-метр входного сигнала (RMS, стиль 500-серии) и встроенный тюнер.
* **Тюнер (MPM):** Высокоточное определение нот алгоритмом **McLeod Pitch Method** с фильтрацией гармоник и отображением отклонения в центах.

### 5. 🏋️ Practice Dashboard — Тренировки
* **Персональные планы тренировок** с уровнями сложности (Beginner → Pro) и категориями (Chords, Scales, Rhythm, Technique, Improv, Ear).
* **Структурированные уроки:** Описание, цель, теория, постановка пальцев, советы, практические шаги.
* **Аудио и табы:** Встроенная озвучка аккордов, гамм и табулатур (с техниками bend, hammer, pull, slide, vibrato).
* **Прогресс и статистика:** Серия тренировочных дней (streak), выполненный план в %, время занятий, уровни навыков по категориям и блокировка упражнений по предпосылкам.
* **Сохранение прогресса:** Всё хранится в `localStorage`, доступен сброс прогресса.

### 6. 🎮 Game Room — Игровая комната
* **Бесплатные браузерные игры** без установки: Shell Shockers, Krunker, Smash Karts, ZombsRoyale, Slither, Paper.io 2, Diep.io, Bloxd.io, Lol Beans, Soccer, Rock N Roll Racing, Tetris, Skribbl, Hole.io, 8 Ball Pool и др.
* **Фильтрация по жанрам:** Shooter, Racing, Battle, Arcade, Puzzle, Party, Sports, Retro.
* **Просмотр в модальном окне** с кнопкой Fullscreen и поддержкой мобильных устройств.

## 🛠 Технологический стек

* **Frontend:** React 18, TypeScript, сборщик Vite
* **Аудио-ядро:** Tone.js (продвинутый транспорт, тайминги, сэмплеры и синтезаторы)
* **Низкоуровневый звук:** Web Audio API + AudioWorklet (расчёт частот, фаз, синтез гармоник, обработка эффектов)
* **AI/ML:** OpenAI-совместимый клиент с фоллбэком на локальную **Ollama** (`aiGenerator.ts`), TouchGrass AI-ассистент
* **Графика и UI:** Кастомный SVG-рендеринг временных шкал и грифа без тяжёлых внешних UI-библиотек
* **SEO/мета:** react-helmet-async, генерация `sitemap.xml` и `robots.txt`

    ├── hooks/              # useEarTrainingAudio, useRecordingAnalyzer, useMetronome, useTuner
    ├── services/
    │   ├── AIEngine.ts     # Генерация соло, фраз, подсказок, AI-запросы
    │   ├── AudioManager.ts # Микшер, сэмплеры, синтез
    │   ├── FretLabRig.ts   # Процессор реального времени
